## 8.88 元这一档，实际拿到的是什么

端口 1000Mbps、月流量 2000GB，这个组合在香港 10 元以内的机器里不常见。多数同价位香港 VPS 给 1TB 流量，或者干脆不标端口。2000GB 摊到每天约 66GB，做代理、跑文件同步、看流媒体都够用。

流量用完之后不停机。官方规格写的是超出后限速到 10Mbps 共享，想恢复满速花 ¥10 重置当月流量。10Mbps 还能维持 1080p 视频和日常网页，不算废掉，但别指望继续跑大流量任务。

内存 1024MB，跑一个代理面板、几个 Docker 容器，或者做 DNS 解锁的中转都够。想在上面开 Windows 或者跑编译，1GB 很快见底。硬盘 10GB，装完系统剩七八个 G，放点配置和小文件没问题，当存储盘用不现实。

CPU 型号官方页面没标。2026 年 6 月的一篇横向评测里，这台显示为 AMD EPYC 7532。这个级别的处理器跑单线程代理没有瓶颈，别指望它做计算。

IP 是广播 IP，地理位置识别为香港，流媒体解锁正常。它既不是原生 IP，也不是家宽 IP。做代理和看流媒体够用；做需要干净 IP 的账号注册、支付类业务，广播 IP 会被风控识别出来。

线路接 TATA、PCCW、COGENT、EIE，属于国际线路，没有中国大陆直连优化。从国内访问的延迟和晚高峰丢包，取决于你当地运营商到香港的国际出口，和 CN2 GIA 那类线路不是一个量级。

IPv6 没有。这一点值得单独说：2025 年初的一些介绍文章写的是“每个套餐默认含 1 个 IPv4 + 1 个 IPv6”，但 2026 年 5 月的官方在售规格和论坛里贴出的套餐信息都写着 1 个 IPv4、0 个 IPv6。以现在的页面为准，需要 IPv6 的人直接排除这一款。

## 哪些人买了会后悔

四种情况不用考虑 HKLite-One：

- **需要 IPv6**。这款没有，官方规格写的是 0 个 IPv6。靠 IPv6 访问的资源和双栈环境，这台机器接不上。
- **业务依赖原生 IP**。广播 IP 在注册、支付、风控严格的场景里会被识别出来。这类需求对应的是懒猫云那种原生家宽机型，不是这台。
- **要求中国大陆低延迟直连**。HKLite 走国际线路，没有 CN2、CMIN2 这类大陆优化，晚高峰体验取决于你本地出口。
- **要跑高并发或大吞吐**。1 核 1GB 不适合重负载，1000Mbps 是端口上限，实际能跑多少还受国际出口限制。

前三条里任何一条成立，这台机器都不用往下看了。只符合第四条，说明你需要的是 Advanced Competitive 那两档，10G 端口加不限流量，价格从 ¥50 起。

## 下单前要确认的四件事

**库存。** HKLite-One 经常处于无货状态，官方页面能付款就是有货，付不了就是没货。已经注册的账号可以去控制台左侧的“交易市场”看别人转手的机器，这是官方提供的二手通道，比在群里找人收安全。

**配置。** 开通后在控制台核对硬盘、流量、端口三项。购物车写 10GB / 2000GB / 1000Mbps，控制台显示 5GB / 1000GB / 5000Mbps，那就是发了 9.9 那个批次，以控制台为准，对不上及时开工单。
